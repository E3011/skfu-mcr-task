# JS-01

Всем привет! Давайте выполним несколько задачек для ознакомления с JS.

## Задачи

В папке [`/tasks/required.js`](./tasks/required.js) содержатся задачи, выполнение которых **ОБЯЗАТЕЛЬНО**!

В папке [`/tasks/optional.js`](./tasks/optional.js) содержатся задачи, выполнение которых **ОПЦИОНАЛЬНО**!
*Для тех, кто хочет погрузиться чуть глубжке*

Все задачи будут покрыты тестами.

## Требования к окружению

Версия ноды, которую я использую — **v24.21.0**.

Проверьте вашу версию:

```bash
node -v
```

Установите нужную версию:

```bash
nvm install 24.21.0
```

Можете попробовать на других версиях и рантаймах, но нет гарантии, что тесты будут работать корректно.

## Запуск тестов

```bash
# Запуск тестов обязательных заданий
npm run test:required

# Запуск тестов опциональных заданий
npm run test:optional

# Запуск всех тестов
npm test
```

## После выполнения обязательно ОТДЕЛЬНЫМ коммитом добавьте фаилы с выводом тестов

```bash
node --test --test-reporter=tap > result.log
```
